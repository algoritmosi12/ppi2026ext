🚀DEVQUEST

Proyecto de Gestión de Software

DESCRIPCIÓN DEL PROYECTO

Necesita un sistema web para gestionar su inventario. El sistema deberá permitir registrar productos, actualizar stock, consultar existencias y generar reportes básicos.

OBJETIVO

Durante la partida deberás enfrentar imprevistos, gestionar el tiempo de desarrollo y utilizar el presupuesto de manera inteligente. Cada decisión tendrá consecuencias que influirán en el éxito o fracaso del proyecto.

🎯 Completa el proyecto antes de que sea demasiado tarde sin superar el presupuesto asignado.

PRESUPUESTO INICIAL: $20.000

TIEMPO DISPONIBLE: 20 'MINUTOS'

EVENTOS ALEATORIOS

Durante el proyecto pueden ocurrir:
Reducción de presupuesto (-$1.000).
Falla crítica del sistema (-2 minutos).
Ausencia de un desarrollador (-$500).
Patrocinador que aporta fondos (+$2.000).

CONDICIÓN DE VICTORIA

Finalizar todas las funcionalidades dentro del presupuesto y el tiempo establecido.
Proyecto completado: 10/10
Proyecto incompleto: 5/10
Presupuesto agotado o tiempo agotado: Proyecto rechazado.
